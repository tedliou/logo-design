# Sources and classic examples

Read when the user asks for references, or wants a style rooted in a specific tradition.

## Classic examples

| Year | Work | Lesson for logos |
|---|---|---|
| 1967 | Wim Crouwel, New Alphabet | Made for early CRT screens: only horizontal and vertical strokes, 45-degree corners. The letters obey the grid instead of faking curves on it. |
| 1978 | Taito, Space Invaders aliens | Drawn as pixel art, then two-frame animation. A low-resolution silhouette became an icon recognized worldwide. |
| 1983-84 | Susan Kare, Macintosh icons and fonts | 16x16 and 32x32, black and white, no anti-aliasing, text avoided. Sketched on graph paper, then refined in Andy Hertzfeld's icon editor. |
| 1984-85 | Zuzana Licko, early Emigre bitmap fonts (collected as Lo-Res in 2001) | Treated low resolution as the aesthetic, not a stopgap. Emigre issue 3 was set entirely in them. |
| 2024 | Sandisk logo by ELA Advertising | One square pixel beside a simplified S, standing for the smallest unit of data. A single pixel can carry the concept. |
| recent | Superfried's identity for agency hifi | Name built from block modules; rearranging the blocks gave 12 variants. Pixel systems extend well into variable identities. |

Kare said in a designboom interview that she explores many directions because there is no single right answer, and is often quoted as "don't try to be original, just try to be good". The triad "meaningful, memorable, clear" is attributed to her only by secondary blogs; mark it as attributed when quoting.
